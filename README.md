# Egyptian Tech Market EDA (2024)

This project explores the Egyptian Tech Market Survey 2024 dataset using exploratory data analysis techniques.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Analysis
- Demographics and experience distribution
- Programming language trends
- Salary and compensation analysis
- Company size and market insights

## Dataset
Source: Kaggle – Egyptian Tech Market Survey 2024

## Outcome
Extracted actionable insights on career progression, skills demand, and compensation patterns.
